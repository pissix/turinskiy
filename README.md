# Ветки. Картинки. GITIGNORE

Учебный репозиторий Туринского Руслана.

В работе используются три ветки: `main`, `feature-image` и `feature-gitignore`.

- `feature-image` — добавление изображения в формате SVG.
- `feature-gitignore` — настройка файла `.gitignore`.

Изменения из рабочих веток объединяются с основной веткой `main` через Pull Request.
